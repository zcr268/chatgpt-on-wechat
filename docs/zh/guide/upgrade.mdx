## 命令升级（推荐）

使用 `cow update` 一键完成代码更新和服务重启：

```bash
cow update
```

该命令会自动完成以下流程：

1. 拉取最新代码（`git pull`）
2. 停止当前服务
3. 更新 Python 依赖
4. 重新安装 CLI
5. 启动服务

<Note>
  如果未安装 Cow CLI，也可以使用 `./run.sh update` 完成相同操作。
</Note>


## 控制台一键更新

源码安装也可以直接在 Web 控制台升级，不必再开终端。

1. 点击左侧栏底部的版本号。打开面板时**不会**访问 GitHub。
2. 点击 **检查更新** 才会拉取新版本说明。这是唯一的网络请求。
3. 若有新版本，点击 **立即更新**。控制台复用 `cow update` 的同一条路径（`git pull`、安装依赖、重装 CLI），然后重启服务。

替换代码前，会把用户数据备份到 `backups/cow-pre-update-<timestamp>.zip`（配置、工作区、技能、知识库、定时任务），并记录当前 git 提交。如果新代码无法 import，会重置回该提交，且不杀死正在运行的进程。

更新成功后，控制台会自动重连并显示新版本号。

<Note>
  Docker 镜像和桌面客户端不能用这个按钮。Docker 仍使用 `docker compose pull`；桌面客户端继续走内置更新。Windows 上请在终端执行 `cow update`，Web 控制台无法从进程内部完成重启。
</Note>

### 回滚

如果更新成功但新版本工作异常：

```bash
cow stop
git reset --hard <previous-commit>   # 更新面板 / tmp/web-update-status.json 中会记录
cow restore backups/cow-pre-update-<timestamp>.zip --yes
cow start
```

`cow restore` 在服务运行时会拒绝执行，所以要先 stop。

## 手动升级

在项目根目录下执行：

```bash
git pull
pip3 install -r requirements.txt
pip3 install -e .
```

更新完成后重启服务：

```bash
# 使用 Cow CLI (推荐)
cow restart

# 或使用 run.sh
./run.sh restart

# 或使用 nohup 直接运行
kill $(ps -ef | grep app.py | grep -v grep | awk '{print $2}')
nohup python3 app.py & tail -f nohup.out
```

## Docker 升级

在 `docker-compose.yml` 所在目录下执行：

```bash
sudo docker compose pull
sudo docker compose up -d
```

<Tip>
  升级前建议备份 `config.json` 配置文件。Docker 环境下如需保留数据，可通过 volume 挂载持久化工作空间目录。
</Tip>

## 客户端升级

[桌面客户端](/zh/guide/desktop)内置自动更新能力，有新版本时会自动检查并提示，一键即可下载并重启完成升级。

你也可以随时前往[下载页](https://cowagent.ai/zh/download/)手动下载最新版本安装。
